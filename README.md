# Holaweb solutions site (South Africa)

Partner edition of the Infooware landing site, branded for Holaweb and focused on South Africa.
Mobile first, SEO and AEO ready, discovery-led (no figures or prices), with a sticky WhatsApp button on every page.

## Before going live
- Replace the placeholder mark in `assets/logo.svg`, `assets/icon-192.png`, `assets/icon-512.png` and `assets/og-image.png` with Holaweb's logo.
- Confirm the WhatsApp and call number (currently +91 63596 93055) and the brand colours.
- Canonical URLs use `https://hemantam1.github.io/holaweb-solutions`. Replace it across the files if the site lives on another domain.

GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
